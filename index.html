    What Prensa actually does

    When you scan a document with a phone, each page is saved as a photograph. Many scanners then store that photograph using Flate, a lossless method designed for flat graphics and text, not for photographs of paper. A single page can eat 9 MB that way.

    Prensa re-encodes those page photographs as JPEG, the format built for exactly this kind of image, and leaves everything else in the file untouched. Page count, page size, text layers and the pixel dimensions of every image stay exactly as they were. Nothing is ever scaled down.

    Honest limits

    • JPEG is lossy. Nothing here is bit-for-bit identical to your original, so keep your originals if a file may ever need to serve as legal or evidentiary proof.
    • A PDF that is mostly real text rather than scans is already small, and Prensa will tell you it could not improve it rather than hand you a worse file.
    • Prensa never returns a file bigger than the one you gave it.
    • Password-protected PDFs are skipped.

    If your browser asks about multiple downloads

    Saving a batch means saving many files in a row, and browsers ask permission the first time. Choose Allow and the rest of the batch lands in your downloads folder on its own. If you miss the prompt, every finished row keeps a Save button.
